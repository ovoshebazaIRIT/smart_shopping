# Умный Шопинг — каркас веб-платформы

Дипломный проект: интеллектуальный помощник для поиска и сравнения товаров.
Текущий этап — **каркас фронтенда**: общая обвязка сайта, роутинг, поиск,
бесконечная лента каталога, личный кабинет и карточка товара.

## Стек

| Слой | Технология |
| --- | --- |
| Разметка | HTML5, один `index.html` |
| Стили | CSS-переменные + обычный CSS, без фреймворков и картинок |
| Логика | JavaScript (ES5-совместимый синтаксис, IIFE-модули) |
| Роутинг | собственный хеш-роутер (`#/search?q=...`) |
| Сборка | не требуется: ни npm, ни бандлера, ни зависимостей |

Скрипты подключены обычными `<script>`, каждый файл добавляет свою часть
в глобальный объект `US`. Поэтому сайт открывается двойным кликом по
`index.html` без сервера и сборки.

## Как запустить

1. Открыть `index.html` в браузере — этого достаточно.
2. Либо поднять статический сервер из папки проекта:

```bash
python -m http.server 4180
# затем http://localhost:4180
```

## Маршруты

| Адрес | Страница | Файл |
| --- | --- | --- |
| `#/` | Главная: рекомендации 4×2 и быстрый переход | `js/views/home.js` |
| `#/search?q=...` | Каталог: фильтры, сортировка, бесконечная лента | `js/views/search.js` |
| `#/search?...&product=<id>` | Карточка товара (модальное окно) | `js/views/product.js` |
| `#/account` | Профиль | `js/views/account.js` |
| `#/account/preferences` | Предпочтения | `js/views/account.js` |
| `#/account/favorites` | Избранное | `js/views/account.js` |
| `#/account/history` | История запросов | `js/views/account.js` |
| любой другой | 404 | `js/views/not-found.js` |

Карточка товара открывается модальным окном, её состояние живёт в адресе
(`?product=<id>`): работают кнопка «назад», перезагрузка и ссылка на товар.
При открытии и закрытии карточки лента не перерисовывается, поэтому позиция
прокрутки сохраняется.

## Бесконечная лента каталога

Каталог отдаётся страницами по 12 карточек (`js/catalog.js`).

- автоподгрузка при подходе к сентинелу (`IntersectionObserver`);
- кнопка «Показать ещё» как фолбэк, если наблюдатель недоступен;
- скелетоны на время загрузки и отдельное состояние ошибки с повтором;
- при смене поиска, категории или сортировки лента сбрасывается и прокручивается вверх;
- дубликаты отсекаются по `product.id` при склейке страниц;
- в конце списка — строка «Показано N из N».

Данные для объёма: 15 товаров в `data.js` плюс 40 в расширении каталога — итого 55.

## Как работает рекомендация

`js/products.js` оценивает предложение по трём факторам:

- итоговая стоимость (цена + доставка) — вес 0.5;
- срок доставки — вес 0.25;
- рейтинг продавца — вес 0.25.

Лучшее предложение получает бейдж «лучший вариант», на его основе строится
текст рекомендации с объяснением выбора.

## Где подключать бэкенд

Демо-данные лежат в `js/data.js` и повторяют форму будущего ответа API.
Точки замены:

1. `js/catalog.js` — `fetchPage` заменяется запросом к агрегатору
   (пагинация, фильтры и сортировка уезжают на сервер);
2. `js/data.js` — вместо массивов данные из API;
3. `js/products.js` — поиск и оценка предложений переносятся на сервер,
   если рекомендации будет считать бэкенд;
4. `js/store.js` — синхронизация избранного с аккаунтом.
